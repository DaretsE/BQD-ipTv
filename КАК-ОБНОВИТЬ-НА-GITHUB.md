# Как залить эту поставку на GitHub

Репозиторий: https://github.com/DaretsE/BQD-ipTv
Работа только через браузер, ничего компилировать локально не нужно.

## Что изменилось

Исправлено подвисание трансляции через несколько минут просмотра.
Больше ничего не трогалось: интерфейс, навигация, настройки, EPG, поиск,
избранное, обновления и откат работают как раньше.

**Изменены 3 файла:**

| Файл | Что в нём поменялось |
|---|---|
| `app/src/main/java/ru/bqd/iptv/Quality.kt` | непрерывная докачка буфера, лимит памяти буфера, живая конфигурация потока, отключено наращивание отставания от эфира |
| `app/src/main/java/ru/bqd/iptv/PlayerActivity.kt` | сторож подвисаний с восстановлением по нарастающей, тихое переподключение вместо перескока на соседний канал, автофреймрейт один раз на канал |
| `app/src/main/java/ru/bqd/iptv/Helpers.kt` | логотипы каналов уменьшаются при декодировании, кэш по памяти вместо кэша по количеству |

Плюс обновлено описание в `СОСТОЯНИЕ-ПРОЕКТА.md` (на сборку не влияет).

**Не изменялись:** `app/build.gradle`, `.github/workflows/build.yml`, `AndroidManifest.xml`,
`Store.kt`, `Models.kt`, все адаптеры, вся разметка и все ресурсы.
Схему версий и секреты подписи трогать не нужно.

## Вариант А — залить только три файла (быстро, 3 минуты)

Так надёжнее: меньше шансов случайно перезаписать что-то лишнее.

Для каждого из трёх файлов:

1. Открой https://github.com/DaretsE/BQD-ipTv
2. Пройди по пути `app` → `src` → `main` → `java` → `ru` → `bqd` → `iptv`
3. Нажми на нужный файл (`Quality.kt`, потом `PlayerActivity.kt`, потом `Helpers.kt`)
4. Нажми карандаш (**Edit this file**) справа сверху
5. Выдели всё содержимое (Ctrl+A) и удали
6. Вставь содержимое одноимённого файла из архива
7. Внизу нажми **Commit changes**, ветка — **main**

Сообщение коммита, например:
`Fix: подвисание трансляции через несколько минут (буфер, живой край, сторож)`

## Вариант Б — залить папку целиком

1. Скачай и распакуй архив. Внутри — папка `BQD-ipTv-main`.
2. Открой https://github.com/DaretsE/BQD-ipTv
3. **Add file → Upload files**
4. Перетащи в окно загрузки папку `app` из распакованного архива
   (перетаскивать нужно именно **папкой**, чтобы сохранились пути).
5. Внизу впиши сообщение коммита, выбери **Commit directly to the main branch**
   и нажми **Commit changes**.

GitHub перезапишет только те файлы, которые реально отличаются.
Папку `.github` трогать не нужно — workflow не менялся.

## Что произойдёт дальше

Push в `main` автоматически запустит сборку (вкладка **Actions**): скачается шрифт
иконок, соберётся и подпишется APK, опубликуется релиз с `BQDiptv.apk` и `version.json`.

На телевизоре: **Настройки → О программе → Проверить обновление**.

## Как проверить, что помогло

Включи канал, на котором раньше начинались подвисания, и оставь его минут на 20–30.
Раньше картинка деградировала по нарастающей и сама не восстанавливалась.
Теперь возможны короткие подгрузки на плохом канале, но плеер их отыгрывает
и возвращается к прямому эфиру сам.

Если где-то поток совсем мёртвый — через несколько попыток появится плашка
«Поток не отвечает. Пробуем восстановить соединение…». Это нормальное поведение:
плеер продолжает переподключаться, а не молча висит, как раньше.

## Если после обновления что-то ведёт себя странно

Настройки → **Качество трансляции**. Полезные комбинации:

- слабый интернет: **Задержка от эфира 20–30 сек** + **При обрыве связи: Упорно**
- рассыпается картинка: **Тип декодера: Программный (SW)**
- очень слабый канал: **Потолок качества: Стабильность**

Размер буфера теперь работает по-настоящему (раньше он упирался в скрытый лимит
по памяти около 10 секунд), так что значения 30 и 60 секунд стали осмысленными.
